# Crush Factory — M4 Gameplay Review 01

双击 CrushFactory.exe，1280×720 Compatibility。免费选择纸箱或铝罐 → PRESS → RETURN → 等待卸载 → COLLECT。赚到 40 金币后打开 UPGRADES，购买 Level 2，最大压力从 80 提升到 100 并解锁轮胎。

空格：压缩/暂停；R：回程；C：领取；N：选物；U：升级；M：声音开关；右键拖动：观察；滚轮：缩放；Esc：退出。

每次只能处理一个物品。必须回程并结算后才能换物。轮胎回弹结束后结算，使用峰值压缩计算奖励，同时显示卸载后的高度。未产生形变的物品奖励为零，但可以免费继续。

奖励 = round(基础价值 × 材质难度 × (0.25 + 0.75 × 峰值压缩率)) + 完成奖励。峰值达到材质目标的 85% 才加完成奖励。纸箱：24 / 1.0 / +6；铝罐：36 / 1.4 / +9；轮胎：50 / 1.8 / +12。

金币、压力等级、解锁、声音设置保存在 Windows 用户目录下的 Godot app_userdata 存档中。每次领取和升级立即保存；退出时不保留正在压缩的物品或未领取奖励。下次启动回到选物状态。

已知限制：只有两个压力等级和三个物品；物品免费，经济数值是 MVP；英文工业界面；未提供云存档或防手动篡改机制；可执行文件未签名。M4 等待 Gameplay 验收，M3 稳定基线为 207ef8d。

存档位置：%APPDATA%\Godot\app_userdata\Crush Factory\progress.json。请勿在游戏运行时手动修改。M4 完整视频与验收结果在同包 evidence 目录和 M4_REVIEW.md。
