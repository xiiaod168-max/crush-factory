# Crush Factory M6 / Content Expansion Prototype

双击 CrushFactory.exe 运行。Compatibility，推荐 1280×720。

选择免费物品 → PRESS → 达到压缩或压力极限后 RETURN → 等待卸载 → COLLECT → UPGRADE。

右侧物品列表可滚动。Level 1：瓶子、纸箱、铝罐；Level 2：轮胎；Level 3：木箱、机箱；Level 4：微波炉。升级费用 40 / 150 / 220 金币，实际压力 80 / 100 / 140 / 180。

Space 压/暂停；R 回程；C 领取；N 选择；U 升级；F3 调试；M 静音；右键拖动观察；滚轮缩放；1/2 正/侧面；Esc 退出。

免费生成保证可持续赚钱。必须归位并结算才能换物品。奖励只领取一次，成功保存后到账。瓶子有少量回弹，轮胎有明显回弹，等待结束再结算。

默认存档：%APPDATA%\Godot\app_userdata\Crush Factory\progress.json。兼容 M5 金币、等级、设置；中途退出放弃当前物品。请勿用旧 M5 程序写入已升到 Level 3/4 的 M6 存档。

本版本新增四种专用结构形变，仍为可控程序化原型；无真实危险飞散碎片。M6 交付后等待用户视觉验收。
